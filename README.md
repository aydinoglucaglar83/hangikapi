# HangiKapı

Trakya sınır kapıları (Kapıkule, Hamzabeyli, Dereköy) ve nakordoni.eu servisleri için mobil uygulama.

- `index.html` — uygulama (GitHub Pages: https://aydinoglucaglar83.github.io/hangikapi/)
- `worker.js` — Cloudflare Worker (gizli NKD_KEY ile nakordoni.eu proxy'si + uygulama sayfası)
- `wrangler.toml` — Cloudflare Workers Builds için ayar

Data by [nakordoni.eu](https://nakordoni.eu)
